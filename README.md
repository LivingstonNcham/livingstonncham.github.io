# Map portfolio

A simple website for your maps. No coding tools needed.

## Files
- index.html: the page (leave as is)
- style.css: the design (leave as is)
- script.js: builds the page (leave as is)
- projects.js: YOUR details and YOUR maps (edit this one)
- maps/: put your map images and PDFs here

## Change your details
Open projects.js in Notepad or any text editor. At the top, replace the
LinkedIn link with your own and add an email if you want a contact button.

## Add a map
1. Export the map as a PNG or JPG (preview, under 5 MB) and, if you like, as a PDF.
2. Put both files in the maps folder.
3. In projects.js, copy one project block, paste it after the last one
   (keep the comma between blocks) and change title, topic, description,
   area, tools, year, image and pdf to match your file names.
4. Delete the three "Sample" blocks when you have your own.

Filter buttons are created automatically from the "topic" of each project.

## Preview on your computer
Double-click index.html.

## Put it online with GitHub Pages
1. Create a free account at github.com.
2. Click New repository. Name it yourusername.github.io (replace with your
   real username). Set it to Public.
3. Click "uploading an existing file", drag in ALL the files and the maps
   folder, then click Commit changes.
4. Open Settings > Pages, choose the main branch and root folder, and Save.
5. After a minute your site is live at https://yourusername.github.io

To add more maps later, upload the new files and the edited projects.js
to the same repository.
